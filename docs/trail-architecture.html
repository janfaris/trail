Trail — Architecture

Cross-vendor AI coding session recorder. Local-first capture, public sharing on demand.

Why local-first

  • • Sessions live on your machine in SQLite
  • • Nothing leaves until trail share
  • • @trail/anonymize scrubs paths + secrets pre-upload
  • • Audit-friendly for skeptical reviewers

Cross-vendor moat

  • • 6 parsers — claude-code, codex, cursor, copilot CLI, copilot chat, hermes
  • • One zod schema across all sources
  • • Anthropic / OpenAI viewers will only cover their own tools
  • • Trail is the neutral public layer

Why Neon over Turso

  • • Mature MCP for agent leverage
  • • Standard Postgres, no lock-in
  • • HTTP driver works in Vercel edge / RSC
  • • Local SQLite + cloud Postgres asymmetry handled by Drizzle

Auth choices

  • • better-auth over Clerk — cheaper, open, no lock-in
  • • Two GitHub OAuth apps (dev localhost + prod)
  • • __Secure- cookie prefix on HTTPS
  • • CLI auth forwards the same session cookie

Distribution

  • • /install page — copy-pasteable 3-step UI
  • • /install.sh — bash installer served as text/plain
  • • Rebuilds better-sqlite3 binding (pnpm v10 quirk)
  • • TODO: npm publish @trail/cli → npm i -g

Deferred / not in stack

  • • Native menu bar app (apps/menubar/, deferred until Dev ID)
  • • Electron / Tauri — overkill
  • • Redis / queues — uploads are sync POSTs
  • • Stripe wired but off (waiting for demand signal)
